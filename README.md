# OSIEL Labs — GitHub organization community files

This public `.github` repository contains the GitHub organization profile and shared community templates for OSIEL Labs.

- [`profile/README.md`](profile/README.md): the public organization overview.
- [`CONTRIBUTING.md`](CONTRIBUTING.md): baseline contribution guidance.
- [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md): expected participation standards.
- [`SECURITY.md`](SECURITY.md): security reporting guidance.
- [`SUPPORT.md`](SUPPORT.md): support and project readiness guidance.
- [`GOVERNANCE.md`](GOVERNANCE.md): repository and decision-making practices.
- [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/): common issue forms.
- [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md): pull request checklist.

These documents provide shared defaults when a repository does not override them with project-specific guidance. They do not declare every OSIEL Labs repository to be open source or ready for external contributions.

## Publishing

GitHub displays `profile/README.md` on the public organization Overview page when this repository is named **`.github`**, belongs to **OSIEL-Labs**, and is **public**.

Project-level policies and licenses take precedence where specified.
