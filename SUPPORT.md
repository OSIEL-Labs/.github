# Support and questions

OSIEL Labs is developing the OSIEL enterprise platform and related infrastructure. Some repositories may be experimental, private or not intended for production use.

## Where to ask

- **Bug reports:** use the repository's issue tracker if enabled, with reproduction steps and expected behavior.
- **Feature proposals:** follow that repository's discussions or issue templates.
- **Usage questions:** start with the repository README and documentation, then use its published support channel.
- **Security concerns:** follow [SECURITY.md](SECURITY.md); never disclose sensitive reports in public issues.

## Availability

Public support, commercial support and release guarantees are not implied by repository visibility. Any support commitments will be stated by the relevant project.
